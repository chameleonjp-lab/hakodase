# 通常プレイ10箱化の決定

日付: 2026年7月28日

## 決定

1. 本日の出荷とエンドレスを10箱へ増やす。
2. 色数は4色とし、同色箱の配分を`4 / 2 / 2 / 2`とする。
3. P3-03Rの`b10c4`に属する12件の厳密検証済み構造だけを使う。
4. 全盤面の厳密最短値を24操作とする。
5. 全盤面の初期直行箱を0件とする。
6. 公開ブラウザでは厳密ソルバーを実行しない。
7. seedから構造、反転、色置換だけを決定論的に組み立てる。
8. 練習は基本操作確認のため2箱のまま残す。
9. 10箱盤面はまだ公式問題集ではないため、問題IDを`preview-`で始める。
10. 本日の出荷は正式ランキングへ送らない。
11. エンドレスの端末内記録は維持するが、公式総合ランキングへ混ぜない。
12. P3-05の人間試遊と正式問題集の作業は別Pull Requestとして継続する。

## 理由

公開中の4箱盤面は操作の理解には使えるが、箱同士の順序判断が少なく、ゲームとしての密度が低い。

一方、P3-03Rでは10箱・4色・厳密最短24操作の独立構造を12件確保し、1001件監査でも初期直行箱0と厳密条件を確認済みである。

このため、完全な公式問題集の完成を待たず、検証済み10箱構造を公開試作へ使用する。

## 禁止事項

- 4箱の旧試作盤面へフォールバックしない。
- 公開ブラウザで候補探索や厳密探索を行わない。
- 24操作を推定値として扱わない。
- 未登録の構造をseedから推測生成しない。
- 10箱化だけを根拠に公式ランキングへ接続しない。
- 練習2箱の記録を通常10箱の記録へ混ぜない。

## 再評価条件

P3-05で人間試遊済み問題集が確定した場合、今回のpreview盤面を正式問題へ置き換える。その際は正式`puzzleId`、問題集版、ランキング条件を別契約で更新する。

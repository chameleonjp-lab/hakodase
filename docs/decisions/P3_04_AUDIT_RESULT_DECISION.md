# P3-04 1001件監査後の進行判断

日付: 2026年7月27日

## 判断

P3-04の監査基盤と1001件実行は合格とする。

P3-03生成器`route-scaffold/2.0.0`の候補品質は不合格とし、P3-05へ進まない。

次工程を次に固定する。

```text
P3-03R: 生成器v2補修
```

## 根拠

GitHub Actions Run `30236109244`で1001件を検査した。

```text
生成成功: 1001
生成失敗: 0
candidate: 429
reject: 572
一意boardHash: 656
一意structureHash: 27
```

572件はすべて`initial-direct-exit`でrejectされた。

profile別:

```text
b09c3: 初期直行箱1個 / 全143件
b11c4: 初期直行箱1個 / 全143件
b13c5: 初期直行箱1個 / 全143件
b14c6: 初期直行箱2個 / 全143件
```

hard ruleを通過した429件に限定すると、一意`structureHash`は3件だった。

```text
b08c3: 1構造
b10c4: 1構造
b12c5: 1構造
```

色置換、箱ID、反転によって`boardHash`は増えているが、パズルの基礎構造は十分に増えていない。

## P3-03Rの必須条件

1. 全profileで`initialDirectExitBlockCount = 0`を満たす。
2. 反転と色置換だけではない、独立した複数の経路構造を追加する。
3. profileごとに一意`structureHash`を5件以上確保する。
4. hard rule通過候補全体で一意`structureHash`を60件以上確保する。
5. 1001件生成を完走する。
6. 厳密最短20〜35操作、盤面データv2、解法再生、同一seed決定性を維持する。
7. P3-04監査を同じseed prefixで再実行し、旧版との比較を残す。
8. 未検証フォールバックを追加しない。

## 数値条件の理由

P3-05では30問以上の人間試遊済み問題を目標にしている。

採用前に難易度、似た問題、実機操作、面白さで候補を落とす余地が必要なため、最低2倍の60構造を暫定下限とする。

各profile5構造は、特定の箱数だけが構造数を占める状態を防ぐ最低条件である。

これらを緩和する場合は、P3-03Rの再監査結果と理由を新しいDecision Logへ記録する。

## P3-05へ進む条件

P3-03Rの再監査で次を確認するまで進まない。

```text
初期直行箱0
hard reject 0を目標
一意structureHash 60以上
各profile 5以上
全候補の厳密最短20〜35操作
生成・解法再生・hash検査の成功
```

P3-05ではこの条件を通った候補から、人間が実際に遊んで採否を決める。

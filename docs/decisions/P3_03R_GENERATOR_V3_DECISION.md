# P3-03R 生成器v3の決定

日付: 2026年7月27日

## 決定

1. P3-03生成器`route-scaffold/2.0.0`を、`route-catalog/3.0.0`へ置き換える。
2. 初期直行箱を含む候補は公式候補へ進めない。
3. 全profile・全テンプレートで`initialDirectExitBlockCount = 0`を必須とする。
4. 色置換や盤面反転だけではない基礎構造を66件固定する。
5. 各profileで5件以上の一意構造を必須とする。
6. 1001件監査後の一意`structureHash`を60件以上とする。
7. 基礎構造はP3-02厳密ソルバーで証明する。
8. 幾何的に分離された経路だけ、独立成分の厳密最短を合成する。
9. 経路間に隣接があるテンプレートは、盤面全体を厳密探索する。
10. 反転・色置換後の解法を必ず再生検証する。
11. 同じseed、profile条件、template条件、生成版、ルール版、solver上限では同じ結果を返す。
12. 未登録profileやtemplateを推測で作らない。
13. 証明できない候補に未検証フォールバックを使用しない。
14. 1001件監査で受け入れ条件を満たさない場合、CLIとGitHub Actionsを失敗させる。
15. P3-05の人間試遊が完了するまで、候補を公開版へ接続しない。

## 厳密証明方式

### 成分証明

経路間にセル重複も上下左右の隣接もない場合、各経路は独立している。

各成分をP3-02で厳密に解き、最短値を合計する。

### 全体証明

経路間に隣接がある場合、成分合成を使わない。

`b14c6`の5構造は盤面全体で厳密探索し、最短28操作を確認する。

この区別を自動判定し、`proofMode: components | global`として記録する。

## 1001件受け入れ条件

```text
検査件数: 1001以上
生成失敗: 0
hard reject: 0
hard rule通過後の一意structureHash: 60以上
各profileの一意structureHash: 5以上
最短操作数: 全件20〜35
初期直行箱: 全件0
```

実測結果:

```text
検査: 1001
生成成功: 1001
生成失敗: 0
candidate: 1001
reject: 0
一意structureHash: 66
初期直行箱: 0
acceptance.passed: true
```

## 理由

- 旧版は1001件中572件に初期直行箱があり、4profileが構造的に不合格だった。
- 旧版でhard ruleを通った429件は、実質3構造しかなかった。
- 30問以上を人間試遊して選ぶには、似ていない候補を最低60構造用意する必要がある。
- 反転と色置換だけで件数を増やしても、遊び方の違いにはならない。
- 一部テンプレートには経路間の隣接があるため、成分合成を無条件に使うと厳密性を失う。
- 公開時に重いソルバーを動かさないため、証明と監査は開発時に完了させる。

## 対象外

- 面白さの最終判定。
- 正式問題IDの付与。
- 公開ゲームへの接続。
- Supabaseランキング。
- 出荷シャッター。

P3-05で人間試遊を行い、66構造から30問以上の正式問題集を目標に採否を決める。
